# 鹰眼 2.0 — 羽毛球过网击球智能判罚系统

面向校园、社区和群众性羽毛球赛事，本系统构建了一套低成本、轻量化的过网击球智能辅助判罚闭环。采用 AR0234 高精度双目全局快门摄像头高速采集比赛画面，在边缘端部署轻量级 YOLO 模型识别羽毛球并生成三维轨迹，融合轨迹机理分析完成过网击球判定，最终通过裁判端二维动画与观众端三维场景进行可视化呈现。

## 端—边—云协同架构

| 端 | 平台 | 职责 |
|----|------|------|
| 边缘 | `SC171/`（广和通 QCS6490） | 双目高速采集、YOLO 推理、双摄立体三角化、上传轨迹 |
| 云端 | `Aliyun/`（云服务器） | 轨迹过滤、过网判罚、2D/3D 渲染、多终端分发 |
| 终端 | `ESP32-P4_Function_EV_Board/` | 裁判触摸计分、UDP 控制、判罚动画播放 |

## 关键指标

- 图像采集：1280×720 @ 160 fps，实际约 149 fps
- 目标检测：精确率 88%、召回率 79%、推理约 98 FPS
- 过网击球综合判罚准确率约 80%
- 整体成本控制在千元级
